# Khila's World — API setup

1. Open `.env` in this folder.
2. Paste the OpenAI Platform key after `OPENAI_API_KEY=`. Do not add spaces.
3. Save the file.
4. Double-click `start-site.cmd`.
5. Open <http://localhost:8787> in a browser.

Keep the server window open while using the site. If you change the key, close the server window and start it again. Never upload `.env`; it is excluded by `.gitignore`.
